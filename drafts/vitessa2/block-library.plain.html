Block Library

All 18 blocks in the AZ Sitebuilder design system.

hero-teaser

Hero Teaser Headline

Full-width hero with background image, gradient overlay for text contrast, and optional CTA button.

Primary CTA Button

hero

Hero (Minimal)

CSS-only hero block. Simpler than hero-teaser — no JS decoration.

title

Title Block

Centred heading for pages without a hero image. CSS-only, no JavaScript.

introduction

Introduction Block

Lead-in text for a section with optional key stat emphasis. Typically paired with section-metadata Style: light for a subtle background.

Style
light

columns-teaser

Columns Teaser Heading

Image + content side-by-side. Ideal for feature highlights, mechanism explanations, and contact sections. Supports heading, multiple paragraphs, and a primary CTA button.

Primary CTA

Style
highlight

columns

Column One

Basic multi-column layout. CSS-only, no JavaScript. Each cell in the row becomes a column. Adds a .columns-N-cols class automatically.

Column Two

Useful for simple side-by-side text content without images or CTAs. Less visual hierarchy than columns-teaser.

Column Three

Supports any number of columns. Responsive — stacks vertically on mobile.

cards-teaser

Card Teaser One

Image + text card with optional CTA. Renders as a 3-column grid on desktop. Best for feature highlights and resource links.

Learn more

Card Teaser Two

Each row in the block markup becomes one card. First cell is the image, second cell is the body content.

View details

Card Teaser Three

Standalone links automatically become buttons. Supports bold headings and descriptive body text.

Get started

cards

Card One

Similar to cards-teaser but renders as a <ul><li> list. Simpler styling, fewer visual features.

Card Two

Use cards-teaser for richer layouts with CTAs. Use cards for simpler lists.

Card Three

Each row becomes a list item with image and text content.

carousel-teaser

Carousel Slide One

Swipeable carousel with dot indicators and arrow navigation. Each row becomes a slide. Needs 2+ rows to enable carousel controls.

Slide one CTA

Carousel Slide Two

Image in the first cell, content in the second cell. Same structure as cards-teaser but with carousel behaviour.

Slide two CTA

Carousel Slide Three

Auto-advances with a configurable interval. Supports swipe gestures on touch devices.

Slide three CTA

tabs-large

Tab One

First Tab Panel

Tabbed interface with large tab buttons. Each row is a tab — first cell is the label, second cell is the panel content. Supports nested blocks inside panels (like table-data).

Tab one CTA

Tab Two

Second Tab Panel

Panel content can include headings, paragraphs, images, tables, and CTA buttons. Only one panel is visible at a time.

Tab Three

Third Tab Panel

Nested blocks inside tab panels are automatically decorated by the tabs-large JavaScript.

accordion

Accordion Item One

Expandable content panel. First cell is the summary label, second cell is the body. Renders as native <details>/<summary> elements for accessibility.

Accordion Item Two

Body content can include paragraphs, lists, links, and any HTML. Ideal for prescribing information, FAQs, and dense reference content that shouldn’t dominate the page.

  • Supports bullet lists
  • Supports inline links
  • Supports bold text
Accordion Item Three
  1. Also supports ordered lists inside the body content.
  2. Multiple items can be open simultaneously.
  3. Commonly used for references and regulatory content at the bottom of every page.

header & footer

The header and footer blocks are loaded automatically by the EDS framework from /{sitename}/nav and /{sitename}/footer. They are not authored into page content — they render on every page via the lazy loading phase in scripts.js. See the header and footer at the top and bottom of this page.

section-metadata

Not a block — a modifier placed at the end of any section to apply styling.

Style: light → #f8f8f8 background

Style: highlight → #f4eef2 background with magenta border-top

The introduction block above uses Style: light. The columns-teaser block above uses Style: highlight.
